# Product images

Placeholder SVGs ship with the site (no more 404s).  
**Replace with Navina pack photos** when ready:

| Default placeholder | Product | Or use photo as |
|---------------------|---------|-----------------|
| `ready-beans.svg` | Ready Beans | `ready-beans.jpg` |
| `yam-plantain.svg` | Yam & Plantain | `yam-plantain.jpg` |
| `sweet-potato.svg` | Sweet Potato | `sweet-potato.jpg` |
| `sku-04.svg` … | Slots 4–6 | matching `.jpg` |

If you use JPG/PNG, update the `image` field in **shop admin** or `products-config.json`  
(e.g. `"image": "images/ready-beans.jpg"`), then publish.

See `../SHOP-ADMIN-GUIDE.md` and `/shop/admin/`.
